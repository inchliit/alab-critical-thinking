# ALAB Critical Thinking

Student presentation and five-case workbook, adapted from the 45-slide ALAB deck and accompanying teaching conversation. Public site: https://inchliit.github.io/alab-critical-thinking/

Open index.html directly or serve this directory with a static web server. No build step, account, tracking, or external runtime is required. Keyboard: left/right arrows, Home/End, O for slide index, F for fullscreen, N for professor notes. The case library includes local answer fields; Save responses downloads them as Markdown. Answers are held only in the current page until saved.

The public package excludes the professor casebook, plaintext speaker scripts, the historical conversation archive, and the original full PDF. Speaker notes are encrypted and unlocked with the shared professor password. Unlocking lasts only in the current page; Lock notes or a reload locks them again. This is a shared password gate, not individual user accounts. UX worked guidance on source pages 40–42 is replaced with student prompts. Page 22 uses anonymous prompts. Slide numbers match the actual 45-page PDF, not the old assistant script numbering.

Visual design follows the owner’s Excel to Excel deck. Source presenter: Joshua I.L. Palisoc. Source closing credit: Felix Concepcion Veroya, Ask Lex PH Academy. Historical data graphics retain their source credits and are used as examples for critical reading, not current factual claims. New teaching prompts are adaptations. The United case uses a separate supplemental reading.

Original presenter photographs and selected visuals are extracted from the supplied ALAB-Critical-Thinking.pptx. The population chart retains its static 1950 frame.
